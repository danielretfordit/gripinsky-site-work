# Новый сайт Академии 3D GRIPINSKY (gripinsky.ru)

Пилот нового сайта вместо Tilda. Бриф: `docs/HANDOFF.md`. Анализ: `docs/analysis/` (UX/UI, маркетинг и SEO, архитектура). Решения: `docs/decisions.md`. Вопросы к заказчице: `docs/open-questions.md`. Прототипы и черновики: `docs/reference/` (только как источник, в сборку не идут).

Общение с заказчицей на русском, коротко.

## Быстрый старт для Codex и других агентов (рабочая копия заказчицы)
Это рабочая копия `danielretfordit/gripinsky-site-work`. Эталонная версия без экспериментов: `danielretfordit/gripinsky-site-preview`. Правки делать здесь, эталон не трогать.

- Установка и проверка: `npm ci`, затем `npm run build`, `npm test`, `npm run lint:copy`, `npm run lint:css`. Перед коммитом все проверки должны пройти.
- Посмотреть сайт: `npm run dev` (http://localhost:4321), админка `/keystatic`.
- Публикация: каждый пуш в `main` за 5–10 минут собирает и выкладывает предпросмотр https://danielretfordit.github.io/gripinsky-site-work/ (`.github/workflows/deploy-pages.yml`).
- Оформление только по `docs/design/guidelines.md` и навыку `.claude/skills/gripinsky-design/SKILL.md`: токены и классы из `src/styles/global.css`, без своих цветов и размеров в px.
- Нельзя:
  - менять расчёт цен вне `src/lib/pricing.ts`;
  - класть секреты в git;
  - править цитаты учеников;
  - публиковать работы и истории без согласия (`consent`);
  - использовать запрещённые слова и символы из раздела «Правила».
- Если меняешь поля данных, правь сразу три места: схему `src/content.config.ts`, админку `keystatic.config.ts` и данные. `npm test` проверяет их совпадение.
- Перед правкой вёрстки проверь страницу на 375 и 1440 px. После правки `node scripts/audit-rhythm.mjs` должен показывать 0 слипшихся мест.

## Команды
- `npm run dev`: dev-сервер на http://localhost:4321 (в Astro 7 уходит в фон; `npx astro dev stop` останавливает). Админка контента: http://localhost:4321/keystatic
- `npm run build`: проверка типов и схем, затем сборка в `dist/`
- `npm run preview`: собранный сайт на :4322
- `npm test`: тесты расчёта цен (`tests/`)
- `npm run lint:copy`: проверка текстов по правилам ниже
- `npm run check:urls`: все адреса из карты собираются или ведут на старый сайт

## Стек
Astro 7 (`output: 'static'`, адаптер Node только для `src/pages/api/*`), Tailwind 4 (токены в `src/styles/global.css`), Preact 10 (только острова в `src/islands/`), nanostores, Content Layer (JSON в `src/content/`, схемы в `src/content.config.ts`), Keystatic (только в dev). Версии закреплены: preact 10.x (не 11), typescript 6.x (не 7).

## Правила
- Адреса как на Tilda: без слэша на конце. Каноникал строится через `src/lib/seo.ts`, без `.html`.
- Цена считается только в `src/lib/pricing.ts` (общий для острова и сервера). Сервер сумму из браузера не принимает.
- Секреты только в `.env` через `astro:env`. В git и в клиентский бандл не попадают.
- Никаких внешних CDN: Inter Variable и JetBrains Mono загружаются локально через `@fontsource-variable`, без Google Fonts и встраивания YouTube. Сеть в РФ: Cloudflare и ngrok не годятся.
- Стиль 04 «Студийный свет» (09.10.2026) поверх варианта 03: единый источник `docs/design/guidelines.md`, витрина `/styleguide`, навык `.claude/skills/gripinsky-design`. Палитра: фон `#111313`, поверхность `#191D1D`, текст `#F1F1EB`, абзацы `#C1C7C0`, подписи `#A1AAA3`, вторая строка заголовка `#A9AEAB` ровным цветом (градиент в тексте запрещён). Лайм `#E7E845` только из списка в гайдлайне (кнопка, черта надзаголовка, главная цитата (без выделения слов), `.btn-signal`, «+» у цифр, активный пункт, фокус, лаймовые поля ИИ и консультации).
- Шрифты: Inter для заголовков (капсом, вес 800), текста, кнопок, надзаголовков и подписей (капсом, разрядка 0.2em, `--type-label`); JetBrains Mono только для счётчиков, номеров и метаданных рендера (`.t-meta`). Рукописный шрифт не используем.
- Кнопки: `.btn.btn-primary` (48 px, поля 18 px, радиус 2 px, `--type-control`), `.btn-secondary` с длинной стрелкой `.arrow-long`, `.btn-signal` (лаймовая рамка) только в блоке без жёлтой кнопки. Пара первого экрана: `HeroActions`.
- Размеры текста назначаются только по роли из `docs/design/text-hierarchy.md` и переменных `--type-*` в `src/styles/global.css`. Для обычных заголовков, абзацев и подписей не вводить локальные `font-size` или `text-[…px]`; плакатные элементы и цены имеют документированные отдельные роли.
- При изменении типографики главной сравнивать computed styles эталона и `/` в одинаковом CSS viewport: 375, 768, 1024, 1180 и 1440 px. Базовый body и `.t-body` используют line-height 1.5; для роли блока допустим только измеренный в варианте 03 локальный интерлиньяж и перенос. Значения статистики используют `--type-stat`, подписи метрик — Inter, служебные надзаголовки — JetBrains Mono. Размер, цвет, вес, межстрочный интервал и переносы должны совпадать с вариантом 03.
- Контейнер до 1360 px, внешние поля 20 px на телефоне и минимум 24 px дальше. Общая шапка `Header.astro` на всех рабочих страницах закреплена и сохраняет одну геометрию и порядок элементов: 78 px (>1100 px), 64 px (561–1100 px), 60 px (≤560 px); на мобильном одна строка без горизонтального переполнения. Все первые экраны с работой строятся общим `HeroWork`: 3:2 текст и фотография, одинаковый размер фоторамки, строка академии со счётчиком над изображением на широком экране и перед изображением на мобильном. Карусели имеют стрелки, автосмену и свайп. Радиус содержательных изображений и карточек — 2 px; обложки курсов и карточки направлений 16:10, плитки работ 4:3, вертикальные кадры 4:5, квадратные элементы 1:1. Применять общие `.media-frame--*` модификаторы, не задавать локальные противоречащие пропорции в одной группе карточек. Сетка, вертикальный ритм, правила теста, шапки и изображений: `docs/design/system.md`.
- Первый экран главной показывает пять опубликованных ученических работ в карусели: все слайды заполняют одну и ту же рамку через `object-fit: cover`, а подпись и счётчик всегда соответствуют активному кадру. Автосмена — каждые 4,8 секунды; кнопки и свайп листают вручную, кнопки остаются выше закреплённой панели корзины. Наведение и фокус не останавливают смену, но системная настройка `prefers-reduced-motion` её отключает.
- H3 в обычном регистре. Последовательность главной: первый экран с работой ученика → пять метрик → направления → тест → курс «ИИ или умри» → работы учеников → «Почему GRIPINSKY» (шесть пунктов) → основатель → отзывы → сообщество → вопросы → консультация.
- Тексты: без « — », «·» и «→» (стрелки только в ссылках вида «Смотреть →»). Цитаты учеников не трогаем. Не писать «диплом», «квалификация», «налоговый вычет», «гарантия трудоустройства». Без таймеров скидок. Зачёркнутая цена только реальная.
- Не публиковать контакты учеников. Работы и истории показываются только при `consent` у человека.
- Мобильная версия обязательна: проверять на 375, 768, 1024, 1440.

- Каталог с 07.10.2026: готовые пакеты сняты с продажи, кроме «Базы 3D-визуализатора». Уровни 1–3 продаются отдельно. Общая корзина SiteCart и quoteSet; старые URL пакетов сохраняются с подбором отдельных курсов.
